    01 — Overview

    Introduction

    This is an exploratory data analysis (EDA) built on yel_exhibitions, a simulated B2B event marketing dataset generated using Python. It models a company running exhibitions, conferences, webinars, and networking events across Europe, tracking lead generation, conversions, deal values, and marketing costs across 50 events and 4,554 leads.

    The goal was to practice real-world SQL while uncovering the kind of insights a marketing team would actually act on: which event types are profitable, where the sales funnel leaks, and whether marketing spend is justified by the returns it generates.

    Goal: Use SQL alone (CTEs, joins, aggregates) to turn a raw events-and-leads dataset into a set of decisions: where to spend more, where to cut, and where the funnel needs fixing.

    Tools: PostgreSQL, DBeaver

    02 — Motivation

    Why This Project?

    I wanted a SQL portfolio project that went beyond simple SELECT and GROUP BY exercises, something that forced me into real join logic, CTEs, and the kind of aggregation traps that only show up once a schema has genuine one-to-many relationships.

    B2B event marketing was a good fit for that. Real datasets in this space are hard to find publicly, so I simulated one in Python: events, leads, funnel stages, deal values, and costs, designed to reflect real-life event marketing data.

    03 — Dataset

    The Data

    The dataset was simulated using Python and loaded into PostgreSQL as two related tables: events and leads, joined on event_id.

    TableRowsKey Columns

    event_type covers Exhibition, Conference, Webinar, and Networking. Exhibitions carry an additional event_subtype (Flagship or Smaller) which turns out to matter a lot later on.

    Known totals used as sanity checks throughout: 4,554 total leads, 398 converted (8.7%), €6,574,080 in revenue, €5,807,400 in marketing cost. Every aggregate query below was checked against these numbers before I trusted it.

    05 — Analysis

    The Fan-Out Problem: Why Naive Joins Break Aggregates

    Before calculating revenue and cost together, I had to solve a common SQL trap. When joining events (one side) to leads (many side), any aggregate on the events columns, like SUM(marketing_cost), gets multiplied once per matching lead row. An event with 200 leads would inflate its cost by 200x before the SUM ever runs.

    The fix: pre-aggregate costs in a CTE before joining, so by the time it enters the query it's already a single number per group, nothing left to fan out.

    06 — Analysis

    Revenue and Cost by Event Type

    WITH revenue_per_event_type AS (
    SELECT e.event_type, SUM(l.deal_value) AS tot_revenue
    FROM leads l
    JOIN events e ON l.event_id = e.event_id
    WHERE l.converted IS TRUE
    GROUP BY e.event_type
),
cost_per_event_type AS (
    SELECT event_type, SUM(marketing_cost) AS tot_cost
    FROM events
    GROUP BY event_type
)
SELECT
    r.event_type,
    r.tot_revenue,
    c.tot_cost,
    ROUND((r.tot_revenue - c.tot_cost)::NUMERIC / c.tot_cost, 2) AS roi
FROM revenue_per_event_type r
JOIN cost_per_event_type c ON r.event_type = c.event_type
ORDER BY roi DESC;

    Costs pre-aggregated in a CTE before joining to revenue: the fan-out fix in practice

    event_typerevenuecostROI
    Exhibition€6,078,780€4,470,300+0.36
    Webinar€89,120€67,200+0.33
    Conference€362,020€1,042,300-0.65
    Networking€44,160€227,600-0.81

    Revenue total: €6,574,080 ✓, matches the known total, confirming the join logic is clean.

    Exhibitions and Webinars are in positive ROI territory. Conference and Networking are actively destroying value: together they consumed €1.27M in marketing spend and returned only €406K in revenue.

    07 — Analysis

    Digging Deeper: Is It a Cost Problem or a Conversion Problem?

    Conference converts at 6.96%, higher than Webinar's 5.95%, yet Conference ROI is -65% while Webinar is +33%. The problem isn't conversion rate. To find where Conference is bleeding, I looked at cost per lead generated. 

    SELECT
    e.event_type,
    SUM(e.leads_generated) AS tot_leads,
    SUM(e.marketing_cost) AS tot_cost,
    ROUND(SUM(e.marketing_cost)::NUMERIC / SUM(e.leads_generated), 2) AS cost_per_lead
FROM events e
GROUP BY e.event_type
ORDER BY cost_per_lead;

    Cost per lead generated, by event type

    event_typeleads_generatedcostcost_per_lead
    Webinar1,258€67,200€53
    Networking249€227,600€914
    Conference785€1,042,300€1,328
    Exhibition2,262€4,470,300€1,976
    Webinars generate leads at €53 each, 25x cheaper than Conference at €1,328. Even though Conference converts at a higher rate, the cost of acquiring each lead is so high that the math never recovers. Conference is an expensive way to get leads that don't generate enough deal value to justify the spend.

    08 — Analysis

    The Hidden Story Inside Exhibitions

    Exhibitions show +36% ROI overall, but that aggregate is masking a significant internal divide. I broke it down by subtype: Flagship vs. Smaller. 

    WITH revenue_per_subtype AS (
    SELECT e.event_subtype, SUM(l.deal_value) AS tot_revenue
    FROM leads l
    JOIN events e ON l.event_id = e.event_id
    WHERE l.converted IS TRUE AND e.event_type = 'Exhibition'
    GROUP BY e.event_subtype
),
cost_per_subtype AS (
    SELECT event_subtype, SUM(marketing_cost) AS tot_cost
    FROM events
    WHERE event_type = 'Exhibition'
    GROUP BY event_subtype
)
SELECT
    r.event_subtype,
    r.tot_revenue,
    c.tot_cost,
    ROUND((r.tot_revenue - c.tot_cost)::NUMERIC / c.tot_cost, 2) AS roi
FROM revenue_per_subtype r
JOIN cost_per_subtype c ON r.event_subtype = c.event_subtype
ORDER BY roi DESC;

    Same fan-out-safe pattern, filtered down to Exhibition subtypes

    event_subtyperevenuecostROI
    Flagship€5,428,640€3,160,600+0.72
    Smaller€650,140€1,309,700-0.50
    Flagship exhibitions deliver +72% ROI. Smaller exhibitions lose money at -50%. The overall +36% is a blended number that obscures the fact that Smaller exhibitions are a drag on the entire category. Flagship events are carrying everything.

    10 — Data Validation

    Trusting the Numbers

    Before trusting any dashboard built on this data, I ran a series of checks to confirm integrity across both tables. 

    -- No negative values in numeric columns
SELECT COUNT(*) FROM events
WHERE registrations < 0 OR attendees < 0
   OR leads_generated < 0 OR leads_converted < 0
   OR marketing_cost < 0;

-- Attendees never exceeds registrations
SELECT COUNT(*) FROM events
WHERE attendees > registrations;

-- Leads count in leads table matches stored count in events table
SELECT e.event_id, e.leads_generated, COUNT(*) AS actual_count
FROM leads l
LEFT JOIN events e ON l.event_id = e.event_id
GROUP BY e.event_id, e.leads_generated
HAVING COUNT(*) <> e.leads_generated;

-- Every converted lead has deal_value and date_converted
SELECT COUNT(*) FROM leads
WHERE converted IS TRUE
  AND (deal_value IS NULL OR date_converted IS NULL);

    Four integrity checks: negatives, attendance logic, cross-table counts, and converted-lead completeness

    All checks returned 0 rows. The dataset is clean and consistent: no negative values, no attendance anomalies, lead counts match across both tables, and every converted lead has the expected fields populated.

    12 — Key Insights

    What I Found

    1. Exhibitions drive 92% of revenue, but only Flagship events are profitable

    Flagship exhibitions deliver +72% ROI. Smaller exhibitions lose money at -50%. The blended +36% Exhibition ROI hides this divide entirely. Budget allocation should concentrate on Flagship events and reconsider the Smaller exhibition programme.

    2. Webinars are the most efficient channel by a wide margin

    At €53 per lead vs. €1,328 for Conference, Webinars are 25x cheaper to acquire leads from and still return +33% ROI. For lead volume at low cost, Webinars are the highest-leverage investment in the portfolio.

    3. Conference and Networking are destroying value

    Combined, these two event types spent €1.27M and returned €406K, a -68% blended ROI. The root cause isn't conversion rate (Conference actually converts better than Webinar) but disproportionately high acquisition costs relative to deal values generated.

    4. 37% of leads are stalled at the Contacted stage

    1,676 leads have been contacted and gone nowhere. This is the single largest untapped opportunity in the funnel: a follow-up problem, not a lead generation problem.

    5. Lead source is not a meaningful conversion driver

    All six lead sources convert within a tight 8–10% band. Optimising for lead source mix is unlikely to move the needle. Volume (Badge Scan) and cost efficiency (Registration Form, Referral) are more useful lenses.

    13 — Conclusion

    Final Thoughts

    The finding that stuck with me most wasn't the ROI split between event types. It was how much a single blended metric can hide. Exhibition ROI looked healthy at +36% until it was broken down by subtype, and the "expensive but converts well" instinct about Conference turned out to be the wrong story entirely once cost-per-lead entered the picture.

    Technically, the most useful lesson was the fan-out problem itself. It's an easy mistake to make with a one-to-many join, and it's the kind of bug that doesn't throw an error. It just quietly inflates a number until a sanity check against a known total catches it. Every aggregate query in this project was built with that check in mind.
